# 膳食本

把 Freeform 里「今天吃了什么、练了什么」和「哪一天做的哪一批自制」对上。

以前的问题是：日记里写 `4/30 榴莲芝士蛋糕`，却不知道这 4 块来自哪一次烘焙。膳食本把这件事拆成三层：

1. **食谱**：配方，可反复用。例如全麦吐司、榴莲芝士蛋糕、开心果酸奶抹酱。
2. **批次**：某一次做出来的实物，带日期、总份数、剩余份数。
3. **日记**：每天吃的东西。如果吃的是自制，就扣对应那一批。

所以 `8/20 吃了 8/30`、`8/21 吃了 4/30` 会明确记在 **8/19 做的那盘蛋糕** 下面，库存变成 `18/30`。

## 本机使用（推荐先这样）

数据存在浏览器 IndexedDB 里，不会上传。iPhone Safari 也可以用。

### 线上地址（需先在 GitHub 打开 Pages）

启用方法见 [DEPLOY.md](./DEPLOY.md)。启用后访问：

**https://mislamaara.github.io/for_cursor/**

### 本地运行

```bash
npm install
npm run dev
```

手机和电脑要在同一网络时，用终端里打印的局域网地址打开。Safari 分享 → **添加到主屏幕**，就接近 Freeform 那样随手记。

首次打开会写入 8/18–8/22 的示例日记，以及三批自制，方便直接看「蛋糕对批次」怎么工作。

## 常用记法

在「记吃的 → 一句话」里可以直接写：

```text
2卤蛋、1片吐司、4/30榴莲芝士蛋糕
```

「吐司」会匹配还没吃完的 **全麦吐司** 批次，「4/30榴莲芝士蛋糕」会扣最近一次未吃完的蛋糕。食堂、牛奶这类没有批次的，就当普通一笔记下。

## 发给 AI

「我的」页可以复制近两周摘要。摘要里自制食物会写成：

```text
4块榴莲芝士蛋糕 ← 榴莲芝士蛋糕 8/19批次
```

不用再导出 Freeform PDF。
